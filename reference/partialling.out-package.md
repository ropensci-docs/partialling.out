# partialling.out: Residuals from Partial Regressions

Creates a data frame with the residuals of partial regressions of the
main explanatory variable and the variable of interest. This method
follows the Frisch-Waugh-Lovell theorem, as explained in Lovell (2008)
[doi:10.3200/JECE.39.1.88-91](https://doi.org/10.3200/JECE.39.1.88-91) .
